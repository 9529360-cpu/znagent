# ZN

ZN is a resident software agent whose identity, state, runtime, tests and release automation belong to this repository. External models are optional cognitive resources; they do not own the runtime.

## Repository layout

- `runtime/python/zn_agent/core/` — resident core
- `tests/zn_agent/core/` — core verification
- `apps/desktop/` — ZN desktop shell and release packaging
- `.github/workflows/` — CI, update smoke and release automation
- `ZN.md` — product architecture contract
- `docs/ZN-SOURCE-EXTRACTION.md` — retained source provenance and extraction record

Historical reference source is not kept in the active development tree.
