# ZN Workbench — 可追溯的执行时间线

## 背景
当前 Work UI 只在技术详情中列出 Resident 的 Body 操作；用户无法快速辨认每次动作的成功或失败，Work 结束后最近操作摘要无法在会话历史中回看。

## 目标
在 ZN 现有 Electron/React 工作台中展示真实的、可展开的动作时间线，并在 Work 完成后保留最近动作的安全摘要。始终坚持 Resident/Work 为唯一事实来源，UI 只展示，不执行任何额外工具。

## 范围
- 正在执行的 Work：在进度区域显示 Resident 上报的最近 Body 动作（类型、成功/失败、完成时间、可展开摘要）及当前工作阶段。
- 已完成的 Work：其 activity 消息包含最多 6 条最近 Body 动作的持久安全摘要，默认折叠以减少长对话噪声；用户手动展开。
- 提供中英文文案、键盘可达的原生 details/summary 和清晰的失败状态。
- 工具输出与活动元数据经现有隐私 choke 后再越过 Resident 持久化边界；只展示短摘要。

## 非目标
不显示模型完整思维链、不假造工具参数、未提供的执行耗时或全量结果、不增加独立 Agent 运行时、不改变任务执行/批准/重放协议、不实现自动重试或新的外部副作用。

## 验收
运行中可辨认已完成动作与当前阶段；断开桌面再连接、Resident 重启后，可通过同一 Work 历史查看最近动作；敏感模式（API Key、private 块等）不出现在投影或会话持久化摘要；切换会话不串流；Windows Electron TypeScript、明确新增的 Vitest 测试与 Python Work 测试通过；全部适用 PR CI 后方可合并。
